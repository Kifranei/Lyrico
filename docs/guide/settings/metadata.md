# 元数据处理

控制元数据文本处理和显示相关的设置。

## 中文文本转换

"中文文本转换"会应用于搜索到的文本元数据和歌词。ID、日期、数字、URL 和封面不会受转换影响。

可选模式：
- 不转换
- 简体转繁体
- 繁体转简体

## 移除空行

开启后，保存歌词和其他多行文本字段时会自动删除其中的空行。

## 非歌词内容过滤

用于在"格式化歌词"中勾选"移除非歌词内容"时，自动清理作词、作曲、来源等非歌词行。

过滤规则在 `设置` → `元数据处理` → `非歌词内容过滤规则` 中维护。规则按完整文本匹配原始歌词行；逐字歌词会先拼成整行后再判断。

常见过滤示例：`作词 :`、`作曲 :`、`编曲 :`、`来源 QQ音乐` 等。

## 艺术家分隔符

多个艺术家写入标签时使用的分隔符。默认分隔符在不同音频格式中可能不同（如 FLAC 使用 `\0` 分隔符，MP3 使用 `; ` 等）。

## 艺术家拆分

**"艺术家拆分规则"** 影响艺术家视图的归类方式。开启后，Lyrico 会将包含多个艺术家的歌曲分别在艺术家中归类。

可以在拆分设置中配置：
- 额外的分隔符（如 `feat.`、`&`、`,` 等）。
- **不拆分明细**：某些艺术家名称不应被拆分（如艺术家名本身就包含分隔符的情况）。

修改分隔符或白名单后，通常需要点击 **"重建艺术家索引"** 才会完全生效。

## 编辑字段

管理编辑页显示哪些字段、按什么顺序显示。内置字段和自定义标签在 **同一份列表** 里，不再分开管理。进入路径：`设置` → `元数据处理` → `编辑字段`。

列表使用单行条目：名称右侧的 **“自”** 表示自定义标签，**“组”** 表示回放增益组合字段。右侧依次为胶囊菜单按钮和开关。

- **长按条目拖动** 调整顺序。封面、评分和歌词各自独立排序；歌词仍保留歌词选项入口。回放增益作为整体移动。
- **菜单 → 管理字段** 仅用于回放增益，打开与歌词内容顺序相同风格的底部面板；长按成员调整内部顺序，右侧开关单独控制显隐。计算、取消和进度固定在回放增益顶部。
- **总开关与内部开关独立保存**：先检查总开关，再显示内部已开启的字段；内部全关时不显示组件。关闭再开启总开关会保留内部选择。
- **开关** 控制编辑页显示及批量匹配可写字段，不会清空歌曲数据。列表顶部的 **“已启用 x / y”** 统计实际启用的字段。
- **菜单 → 查看歌曲** 打开 **“已填写 / 未填写”** 两个标签页，支持左右滑动。回放增益整体查询会将至少有一个回放增益字段的歌曲归入“已填写”，成员菜单则只查询该成员。
- **菜单 → 删除** 仅用于自定义标签，确认后从配置中移除，不删除歌曲数据。
- **顶栏恢复默认图标** 经确认后重置顺序、总开关和成员显隐，并从配置中移除自定义标签；歌曲数据不受影响。

默认开启全部字段，顺序沿用旧版单曲编辑页：封面、评分、基础信息、音轨信息、署名字段、回放增益、歌词。已有自定义顺序和显隐选择仍然保留，恢复默认后应用上述设置。

主列表顺序和回放增益内部顺序会保存到同一份配置，由单曲编辑页、批量编辑页和批量匹配共同使用。

### 内置字段

内置字段来自音频标签本身，只能改顺序和显隐，不能从列表里删除。

以下字段只影响单个页面：

- **歌词偏移**：只在批量编辑页出现（单曲编辑页用歌词选项里的偏移调整）。

### 自定义标签

自定义标签是音频文件里用户自己写入的标签键（例如 `SOURCE`、`MOOD`）：

- 顶部右侧的 **"+"** 用来新增：可以从 **"音乐库里发现的标签"** 里挑一个扫描到的 key（按键的使用次数从多到少排列），也可以手动输入 key 名。键名会自动去除首尾空白并转为大写；输入为空、包含换行、超过 64 个字符或与已有标签重复时，会提示具体原因。
- 自定义标签在列表里带 **“自”** 标记，可通过菜单删除（删除会先确认）。删除只是从列表里移除，**不会删除歌曲里已有的数据**，之后重新添加即可再次看到。

### 关于封面

封面查询会读取音频文件，歌曲较多时需要等待。读取失败的文件不会被误归入“没有该字段”。每个标签页最多显示 500 首，超过时会提示。

## 配置字符映射

用于批量重命名时，将文件名中的特定字符替换为其他字符。

在字符映射页中，点击字符可修改其替换规则。每个字符可以映射到不同的替换值。常见用法例如将 `/` 替换为 `-`，或将 `:` 替换为 `_` 等不适合作为文件名的字符。
